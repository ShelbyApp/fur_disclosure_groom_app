# Fur Disclosure owner app style guide

The visual reference is the 32-image **Fur Disclosure Owner Screens v1** study. Screen 07 sets the headline, slider and button treatment. Screen 09 sets the compact illustrated field cards. Screens 06 and 12 set the numbered image notes. Screen 17 sets the care preference rows.

| Element | Treatment |
| --- | --- |
| Canvas | Warm cream #FFFAF0, maximum outer width 432px. Desktop centers the same screen on pale yellow. |
| Headlines | Fredoka, deep plum #422052, tightly set. Small yellow rays accent the heading. |
| Body | Nunito Sans at 16px, with permanent input labels. |
| Choices | Thin violet outlines, rounded corners, lilac selected fills, radio dots or checkmarks. |
| Primary action | Wide violet pill with a yellow lower edge, followed by the text link to finish later. |
| Imagery | The garden dog and field illustrations come from the original screen 09 artwork. The guide dogs come from the existing Fur Disclosure breed image library. |
| Identity | Use the folded-document dog logo, the dog’s own face photo when available in Advanced, and the sample avatar otherwise. |
| Annotation | Keep image proportions. Use a yellow ring and numbered violet marker, paired with a numbered text list. Touch, mouse, named-area entry and keyboard placement are supported. |
| Wider screens | Keep the phone layout and the same controls. Print uses the paper width and shows saved notes alongside each image. |
| Login and signup | Match the header, intro spacing, yellow “What we got” hero photo, email and password fields. Signup adds confirm password and its primary action. Put the return-to-login link below the form. Guest entry is hidden. |
| Shared line icons | Keep fill, stroke and line styling directly on every shape in parade-doodles.svg. Mobile Safari does not reliably apply a separate style block when an external symbol is referenced. Preserve the versioned asset URL when changing this shared set. |
| Dog lookbook | Warm yellow panel; white Polaroid borders, lilac and yellow tape, subtle tilt and shadow. Captions use Fredoka. One large card with a glimpse of the next encourages swiping. Place the purple + action above the cards at the upper right. |
