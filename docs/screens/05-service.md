# What’s the plan?

**Route:** `#/service` · **Stage:** The groom · **Design reference:** 04

## Purpose

Pick a service and what matters most to you.

## Inputs and displayed content

- **Service** — radio · required: Bath + haircut / Bath + tidy / Bath only / Discuss with my groomer
- **What matters most? Choose up to two.** — chips · optional: Easy upkeep / Keep some fluff / Match my photo / Comfort first (maximum 2)
- **My top priority** — note · optional

## Navigation

basic haircut path: [dog](03-dog.md) → [service](05-service.md) → [coat](11-coat.md). advanced haircut path: [current-photos](04-current-photos.md) → [service](05-service.md) → [inspiration](06-inspiration.md).

## Behavior and acceptance

Service and planning mode are independent. Both can request a haircut. Pick one service and up to two priorities. Basic continues to coat and omits the photo priority. Advanced bath-only also skips the haircut chapter.
