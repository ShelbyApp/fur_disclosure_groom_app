# Usual care and what-ifs

**Route** `#/dog-care` with dog ID

Separate next page after dog basics. Set nervous level and independent defaults for matting, extra time, fees, distress and missed contact. Empty values mean Choose at each visit. Saving preserves weight and any other existing defaults, then returns to the dog profile. A link edits the dog’s basic details. Default changes apply to future fresh visits, not historical plans or active drafts.
