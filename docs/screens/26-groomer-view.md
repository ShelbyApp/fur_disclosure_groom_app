# Groomer’s copy.

**Route:** `#/groomer-view` · **Stage:** Role / visit handoff · **Design reference:** New · local groomer handoff

## Purpose

See the plan prepared in this tab, with the owner’s care notes and limits.

## Inputs and displayed content

Read-only snapshot or an empty state when the owner has not finished.

## Navigation

An empty reader links to the owner flow. A finished copy can be printed.

## Behavior and acceptance

With no finished plan, show an empty state and link to owner intake. With one, display the same filtered snapshot and monochrome portrait presentation as the printable sheet, including the Basic/Advanced badge, prioritized care notes, separate permissions and contact-sharing choice. Uploaded photos remain in an on-screen gallery; only the saved guide and written annotations print. The photo-sharing QR space is reserved, not active. No queue, network lookup, change approval, account or access to another browser’s data.
