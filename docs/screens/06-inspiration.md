# Show the groom you mean.

**Route:** `#/inspiration` · **Stage:** The groom · **Design reference:** 05–06

## Purpose

A past groom or inspiration photo can say more than “just a trim.”

## Inputs and displayed content

- **Desired groom** — photo · optional
- **Where is this look from?** — text · optional
- **What do you like about it?** — note · optional
- **Second desired look** — photo · optional

## Navigation

advanced haircut path: [service](05-service.md) → [inspiration](06-inspiration.md) → [finish](07-finish.md). Advanced only. Bath-only skips this chapter. Remaining look details can be skipped.

## Behavior and acceptance

Advanced haircut or tidy visits can include two independent reference photos, an optional source and an overall note. Tap the actual photo to add numbered placement notes. Each pin has an optional area and required owner text. Changing or removing one photo leaves the other intact.

Photo controls accept JPEG, PNG and WebP up to 12 MB. Resize locally, keep a thumbnail and report a readable error without losing the draft.
