# Add to the lookbook

**Route** `#/add-photo` with dog ID

Choose a file or take a photo using the device camera when supported. Accept JPEG, PNG and WebP up to 12 MB. Resize locally to at most 900px and save as JPEG, with a preview and optional caption of up to 120 characters. Disable saving until the photo is ready. Errors keep the selected image and caption available for retry. Saving returns to the selected dog’s lookbook. Identical photos of the same dog are stored once. Photos are private to the signed-in owner.
