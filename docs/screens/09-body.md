# Body, legs & little details.

**Route:** `#/body` · **Stage:** The groom · **Design reference:** 09

## Purpose

A length is a request for your groomer to confirm after checking the coat.

## Inputs and displayed content

- **Body length** — radio · optional: Shorter / Medium / Longer / Discuss
- **Requested remaining length** — text · optional
- **Legs** — radio · optional: Match body / Slightly fuller / Discuss
- **Paws** — radio · optional: Tidy outline / Keep natural / Discuss
- **Body notes** — note · optional

## Navigation

advanced haircut path: [face](08-face.md) → [body](09-body.md) → [ears-tail](10-ears-tail.md). Advanced only. Bath-only skips this chapter. Remaining look details can be skipped.

## Behavior and acceptance

Capture body, legs and paws separately. Free text can describe a remaining length for the groomer to confirm.
