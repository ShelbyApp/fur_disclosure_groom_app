# Dog profile

**Route** `#/dog-profile` with dog ID

The identity card opens dog-care to edit usual care and defaults; no duplicate edit link appears below it. Show breed, birthday, current preferences, any resumable draft, and a new groom action. A saved-groomer selector prefills a new visit; resuming keeps the existing draft. Groom History lists the latest three saved grooms with dates and service, followed by Entire Groom History linking to the complete paginated list. The bottom Lookbook shows dog photos in taped Polaroid cards, swiped horizontally with keyboard scrolling supported. A 44px + button at the upper right opens add-photo. Fetch 12 photos at a time with a More photos control. An empty Polaroid invites the first upload. Images from completed grooms join automatically; inspiration photos do not.

Each Polaroid displays Private/Public and the optional provider name beneath its caption. Tap a photo to open edit-photo, where sharing can be reversed or the tag changed. This is the owner’s private management view; the future public community page reads only the restricted public projection.
