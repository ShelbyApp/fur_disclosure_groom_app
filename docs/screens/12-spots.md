# Show the sensitive spots.

**Route:** `#/spots` · **Stage:** Care needs · **Design reference:** 12–13

## Purpose

Tap the spot on the guide dog. Tell your groomer what to look out for.

## Inputs and displayed content

Guide body shape; optional point on the image; optional area name; required note text for each saved pin. Edit and delete are available for every pin.

## Navigation

Open from coat, handling, what-ifs or care review. Save returns to the origin.

## Behavior and acceptance

Choose a doodle, terrier or spaniel guide and tap any location. Add an area and a note, edit or delete existing notes, or add a text-only area. Arrow keys position the keyboard pointer. The guide stays fixed while it has notes. Both modes show sensitive spots in review, the groomer copy and print. Older flagged coat detail remains readable.
