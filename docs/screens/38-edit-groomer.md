# Groomer details

**Route** `#/edit-groomer` with a groomer ID or new

Add or edit one owner’s saved groomer. Require a person or business name, keeping the two separate. New entries require a city and offer independent grooming/daycare/boarding and salon/mobile flags; unchecked flags remain unknown. The contact is immediately usable by its owner and a suggestion enters the private review queue. Existing contact edits affect only the owner's copy.

Normally save returns to the household. The /new/visit variant opens from directory search; Save & use this groomer selects the contact and returns to the same draft. Back preserves the draft. Only a matching signed-in owner, dog and draft can receive the selection. The return context survives refresh. See [Directory](../DIRECTORY.md).
