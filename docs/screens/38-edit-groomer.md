# Groomer details

**Route** `#/edit-groomer` with a groomer ID or new

Add or edit one owner’s saved groomer. Require individual groomer name. Business, street address, email and phone are optional. Keep person and business separate. Save returns to the household. Supports multiple contacts now; choosing from a public directory is deferred.
