# Groomer details

**Route** `#/edit-groomer` with a groomer ID or new

Add or edit one owner’s saved groomer. Require individual groomer name. Business, street address, email and phone are optional. Keep person and business separate. Normally save returns to the household. The /new/visit variant opens from groom creation; Save & use this groomer saves to the same profile, selects the new contact and returns to that draft’s visit screen. Back cancels and preserves the draft. Only a matching signed-in owner, dog and draft can receive the saved selection. The return context survives refresh. Supports multiple contacts now; a public directory is deferred.
