# Owner sign-in

**Route** `#/account`

Use the yellow “What we got” hero dog photo from the landing page. Log in with email and password to open the existing household. Offer Create an account and Forgot password. The dog photo, email and password align with the account creation screen. Continue as a guest is hidden for this iteration.
