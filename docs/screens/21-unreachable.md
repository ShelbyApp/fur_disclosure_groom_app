# If we miss each other.

**Route:** `#/unreachable` · **Stage:** What-ifs · **Design reference:** 23

## Purpose

No reply is not permission. New changes still need the appropriate approval.

## Inputs and displayed content

- **If you can’t be reached…** — radio · required: Pause work needing new permission / Complete only work already agreed / Stop and arrange collection

## Navigation

Selectable in [what-ifs](15-what-ifs.md) or individually from review. Save returns to the originating screen.

## Behavior and acceptance

A missed call does not authorize new work. An explicit preference is required.
