# How’s the coat today?

**Route:** `#/coat` · **Stage:** Care needs · **Design reference:** 11

## Purpose

Share what you’ve noticed. Your groomer will check the coat in person.

## Inputs and displayed content

- **Coat condition** — radio · required: No tangles noticed / Some tangles / Tight or widespread mats / Not sure
- **Last professional groom** — text · optional
- **Brushing at home** — text · optional
- **Coat notes** — note · optional
